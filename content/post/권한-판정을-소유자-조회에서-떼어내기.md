소유자 정보를 가져오는 함수가 접근 권한까지 판정하면, 조회 목적이 다른 코드가 권한 규칙에 묶인다. 자원 조회와 접근 판정을 분리하면 각 책임을 독립적으로 테스트하고 재사용할 수 있다.

```python
item = await repository.get(item_id)
if item is None:
    raise NotFound()
if not policy.can_read(actor, item):
    raise Forbidden()
```

권한 규칙은 화면이나 라우터마다 복사하지 말고 명시적인 정책 함수에 둔다. 자원 종류별로 소유자 모델이 다르다면 공통으로 보장되는 속성만 계약으로 삼고, 실제 접근 규칙은 정책에서 다룬다.

존재하지 않는 자원과 권한이 없는 자원을 같은 응답으로 처리할지는 정보 노출 위협 모델에 따라 정한다. 이 차이를 명확히 한 뒤 테스트로 고정한다.
