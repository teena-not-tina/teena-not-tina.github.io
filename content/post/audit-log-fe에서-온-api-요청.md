---

감사 로그는 누가 어떤 작업을 했는지 나중에 확인하기 위한 기록이다. 서비스 구현이나 실제 사용자 데이터를 드러내지 않도록, 여기서는 일반적인 필드만 정리한다.

```text
actor_id       작업을 수행한 주체의 가명 또는 내부 식별자
resource_type  영향을 받은 자원의 종류
resource_id    영향을 받은 자원의 식별자
action         수행한 작업
status         성공 또는 실패
request_id     관련 요청을 찾기 위한 임의 ID
created_at     기록 시각
```

요청 본문 전체, 인증 정보, 개인 식별 정보는 기본적으로 기록하지 않는다. 디버깅에 꼭 필요한 값만 허용 목록으로 골라 남기고, 보관 기간과 열람 권한도 함께 정한다.

제품마다 필드와 정책이 다르므로 이 목록은 합성 예시이며 특정 회사의 스키마를 설명하지 않는다.
